### Step 1: Read
- Start with **README.md** for overview
- Read **SETUP_GUIDE.md** for detailed setup

### Step 2: Setup (15 minutes)
```bash
# Install dependencies
npm install

# Setup databases (PostgreSQL & MongoDB)
# See SETUP_GUIDE.md for database setup

# Configure .env files
# Use .env.example as template

# Get GROQ API key from console.groq.com
```

### Step 3: Run
```bash
npm run dev
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
```

### Step 4: Demo
- Click "Register" to create citizen account
- Report an issue with photo

- Track complaint progress
- Provide feedback

- Add your city/area names

- Add real GROQ API key
- Deploy to production

## 🔧 Tech Stack Summary

| Component | Technology | Why Chosen |
|-----------|-----------|-----------|
| Frontend | React 18 + Tailwind | Modern, component-based, beautiful UI |
| Backend | Node.js + Express | JavaScript full-stack, fast, scalable |
| Auth DB | PostgreSQL | Reliable, ACID compliant, secure |
| Data DB | MongoDB | Flexible schema, scales horizontally |
| AI | GROQ Mixtral | Free tier, fast inference, great quality |
| State | Zustand | Lightweight, easy to use |
| Maps | Leaflet.js | Open-source, no keys needed |
| Charts | Chart.js | Simple, powerful, responsive |
| Styling | Tailwind CSS | Utility-first, fast development |
| HTTP | Axios | Simple, promise-based |
